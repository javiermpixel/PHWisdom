# Shop megamenu

In the theme editor, open Header → PH Wisdom Shop megamenu.

- Enable/disable the custom menu and set the matching menu item name (Shop by default).
- Reorder the six Shop category blocks. Select a collection and optionally override its title, small heading, description and editorial image. The initial bundled images reproduce Figma; clear “Theme image filename” to use the collection image instead.
- Reorder/edit Shop brand blocks, or select a Brands menu to manage those links in Shopify Content → Menus. The menu takes priority over the blocks. Brands deliberately use collections because the catalog's vendor values do not represent its brands.
- Select and reorder up to 12 Featured products. Images, titles and links follow the product records. If the selection is empty, the fallback collection supplies up to 12 products.
- Labels are editable in the Header settings. Desktop opens on hover, click or keyboard. Moving from Shop into the panel keeps it open; leaving closes it after a short delay unless keyboard focus remains inside. Escape, outside click and focus leaving also close it. Mobile uses an accordion with the same content.

Initial category destinations: electrolyte-mix, sports-nutrition, vitamins-and-supplements, real-salt, olive-oil, skin-and-natural-beauty. Adjust the last two if broader merchandising collections are created.
